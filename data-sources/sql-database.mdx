In Softr, you can build data-driven apps with **PostgreSQL, MySQL, SQL Server, and MariaDB** as data sources.

With SQL data sources, you can:

* Show your structured data in **custom apps and dashboards**

* Enable **secure access** for internal teams and external partners

* Scale without hitting **record limitations**

<Info>SQL data sources are available on Business and Enterprise plans.</Info>

## **1. Connect your SQL database to Softr**

Before you connect, make sure you have:

* Your **SQL database credentials**: host, port, database name, user, and password.

* Permission to access the database.

<Steps>
  <Step title="Open Integrations">
    1. In the [Softr Studio dashboard](https://studio.softr.io/dashboard/integrations), click **Integrations** in the left menu.

    2. Click **Connect new**.

    <Frame>![The Integrations page of the dashboard, with the Connect new button](/data-sources/images/shared/integrations.png)</Frame>

    3. In the **Select an integration** window, click **PostgreSQL**, **MySQL**, **SQL Server**, or **MariaDB**.

    <Frame caption="The Select an integration window with PostgreSQL selected">![The Select an integration window with PostgreSQL selected](/data-sources/images/sql-database/select-postgresql-integration.png)</Frame>
  </Step>
  <Step title="Enter your database credentials">
    The connect window asks for these fields:

    * **Name**: A name that helps you recognize the connection in Softr.

    * **Host**: The database server address, for example `db.example.com`.

    * **Port**: The port your server uses. Softr fills in the default port for the database type: `5432` for PostgreSQL, `3306` for MySQL and MariaDB, and `1433` for SQL Server.

    * **Database**: The name of your database.

    * **User**: Your database username.

    * **Password**: Your database password.

    <Frame caption="The Connect to PostgreSQL database window">![The Connect to PostgreSQL database window with the Name, Host, Port, Database, User, and Password fields filled in](/data-sources/images/sql-database/connect-postgresql.png)</Frame>
  </Step>
  <Step title="Confirm your setup">
    Click **Connect** to verify and establish the connection. If the connection fails, check your credentials and try again.
  </Step>
</Steps>

## **2. Connect your SQL data to your Softr app**

Once your SQL account is connected, you can use it in any Softr application.

<Steps>
  <Step title="Connect your data to a dynamic block">
    To display your data in the app, connect a [dynamic block](/core-concepts-overview/c5VwEbsWtTfPyUZjmEKvfx/visualize-data-with-building-blocks/41p6U2eZs7zgY8zWmFV4eH#1859a723d691803d9551ecd7b3b0c043) (for example, [List](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/list-block/pQhPYuA28VXr5tLLFBcbCU), [Grid](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/grid-block/42JZoeYwMsogZcveqh74QH), or [Table](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/table-block-/j7rGwu7J7zuU69h3bZ7HFe)) to your SQL table:

    1. Go to the block **Source** tab and select your SQL account in **Account**.

    2. Select the **database** you want to use.

    3. For PostgreSQL and SQL Server, select the **schema**. MySQL and MariaDB have no schema field.

    4. Select the **table** you want to use, or add a new **query**.

    5. Optionally, select the **primary field**.

    <Frame caption="The Source tab of a List block connected to a PostgreSQL table">![The Source tab of a List block with the Account, Database, Schema, and Table fields filled in](/data-sources/images/sql-database/list-source-panel.png)</Frame>
  </Step>
  <Step title="Map Fields">
    When you connect your table to a block, you can choose which table **properties** to display and map to Softr fields. This lets you control how your data appears in Softr.

    **Example:** If you have an **email field** in the SQL database, select **an email field** in Softr.

    <Frame caption="Mapping an image field">![The Avatar URL field window with Display type set to Image](/data-sources/images/sql-database/map-image-field.png)</Frame>
  </Step>
</Steps>
### **Restricting IP Access**

If needed, add Softr’s IPs to your database’s **allowed list**:

* `3.120.79.212`

* `3.123.159.186`

* `52.58.246.121`

## **FAQs**
   <AccordionGroup>
   <Accordion title="Can I update my SQL database from Softr?">
Yes! You can create forms in Softr that **write data back** to your SQL database.
   </Accordion>
   <Accordion title="Is my SQL data secure?">
Absolutely! Softr uses **industry-standard encryption** to protect your data.
   </Accordion>
   <Accordion title="Can I connect multiple databases to one Softr app?">
Yes! You can connect **multiple SQL databases** and use them within the same app.
   </Accordion>

</AccordionGroup>

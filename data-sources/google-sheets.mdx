Google Sheets is a cloud-based spreadsheet solution used by millions worldwide. While it may not be as powerful as Airtable in terms of data management, it is a popular and free tool that many users already rely on. In this guide, we'll walk you through **connecting Google Sheets as a data source** for your Softr app and discuss some of its **advantages and limitations**. Google Sheets is available on all plans, including Free.

<iframe src="https://www.youtube.com/embed/dte3kfZ8Ky4?rel=0" width="100%" height="500px" title="YouTube video"></iframe>

## **1. Connecting your Google Sheets account**

To start using Google Sheets in Softr, you must first connect your account.

* Open the **Integrations** page in the Studio sidebar.

* Click **Connect new**.
<Frame>![The Integrations page with the Connect new button](/data-sources/images/shared/integrations.png)</Frame>

* Select **Google Sheets**. The **Connect to Google Sheets** window opens.

* Click **Connect**, then log in to your Google account.

* Check all required permission boxes.
<Frame>![The Connect to Google Sheets window with the Connect button highlighted](/data-sources/images/google-sheets/connect-google-sheets-window.png)</Frame>

## **2. Connect your Google Sheet data to your Softr app**

Once your Google Sheets account is connected, you can use it in any Softr application.

<Steps>
  <Step title="Connect your data to a dynamic block">
    To display your data in the app, connect a **dynamic block** to your Google Sheet.

    1. Go to the block **Source** tab and select your Google Sheets account.

    2. Select the **Document** you want to connect.

    3. Select the **Sheet** you want to use.<br/>
       <Frame>![The Source tab of a List block, with Document set to Help Desk by Softr and Sheet set to Teammates](/data-sources/images/google-sheets/source-tab-document-and-sheet.png)</Frame>
  </Step>
  <Step title="Step 2. Mapping Google Sheets columns to Softr field">
    <Tip>

    When mapping Sheets data to Softr, it’s best to have at least 1 row of sample data in each table/sheet so that Softr can properly determine the field types.

    </Tip>

    Google Sheets stores data in a table format, where each **column represents a field**, and each **row is a record**. To ensure smooth integration, structure your sheet with:

    * **The first row as field names** (e.g., "Assignee," "Status," "Description").

    * **Data stored in rows** under the appropriate column headers.
      <Frame caption="Field names and values on Google Sheets">![Google Sheets sheet with the columns Assignee, Email, Description, Project and Status](/data-sources/images/google-sheets/field-names-in-sheet.png)</Frame>

    When you connect a block to a sheet, you can choose which sheet **columns** to display and map each one to a Softr field. In the block's **Content** tab, click an item field, such as **Photo**, to change how it displays. An image field needs a column that holds image URLs.
    <Frame caption="Mapping an image column to an Image field">![The Content tab of a List block, with the Photo item field set to the Image display type](/data-sources/images/google-sheets/content-photo-image-field.png)</Frame>
  </Step>
</Steps>

### **Record ID Column**

Once you connect a sheet to Softr, a **Softr Record ID** column is automatically added. This unique ID helps Softr reference records (e.g., linking a List block to a List Details block).

<Warning>

**Ensure you have edit permissions** for your Google Sheet so Softr can add and update this column. Do not delete it.
</Warning>
<Frame caption="The Record ID column created inside the sheet">![Google Sheets with the Softr Record ID column in column F](/data-sources/images/google-sheets/softr-record-id-column.png)</Frame>
<Tip>

**Tip**: Use **Softr Record IDs** to link related records across sheets (e.g., setting a "Manager ID" as another user's Softr ID).

</Tip>

### **Supported Field Types in Softr**

Google Sheets doesn’t have built-in field types like Airtable, but you can organize data to match Softr’s supported formats.

**Supported Field Types & Workarounds**

* **Text**: Standard text fields.

* **Number**: Whole numbers, decimals, currency.

* **Date & Time**: Standard date formats. See below for supported formats:

* **Checkbox**: Use "true" (checked) or "false" (unchecked).

* **Image, File, Video/Audio**: Store file URLs. If storing multiple image URLs in the same cell, separate them with a comma

* **Tag Field**: Separate multiple values with commas.

* **Rating**: Use integer values from 1 to 5.

* **File Uploads:** Google Sheets doesn’t support direct file uploads. Use URLs instead.

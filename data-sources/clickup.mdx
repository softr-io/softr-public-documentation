ClickUp is a comprehensive project management and productivity tool that you can use to manage projects, clients, tasks, files, and more. Softr supports all Lists within ClickUp. This allows you to:

* Connect your ClickUp data to Softr for a branded app

* Read, write, update, and delete data in ClickUp from within your Softr app

* Share with external parties or larger groups without sacrificing privacy or paying for each access

<Tip>

ClickUp as a data source is available on Softr’s **Professional** plan and above. It is not available on the Free and Basic plans.

</Tip>

## Connect ClickUp Data to Softr

<Steps>
  <Step title="Add ClickUp as a data source">
    In your Softr workspace, click **Integrations** in the left menu.
    <Frame caption="Click Integrations in the left menu">![Integrations page in the Studio left menu, with the Connect new button](/data-sources/images/shared/integrations.png)</Frame>

    Click **Connect new**.

    Click the **ClickUp** tile in the list of data sources.
    <Frame caption="Click the ClickUp tile">![Select an integration window with the ClickUp tile highlighted](/data-sources/images/clickup/picker-clickup-tile.png)</Frame>

    In the Connect to ClickUp window, click **Connect**.
    <Frame caption="Click Connect in the Connect to ClickUp window">![Connect to ClickUp window with the Connect button highlighted](/data-sources/images/clickup/connect-clickup-window.png)</Frame>

    If you are not signed in to ClickUp, sign in first. Then select the Workspaces you want to connect to Softr and click **Connect Workspace**.
    <Frame caption="Select the Workspaces, then click Connect Workspace">![ClickUp screen to select the Workspaces to connect with Softr](/data-sources/images/clickup/clickup-workspace-selection-third-party.png)</Frame>

    Softr opens again. Your ClickUp connection now appears in the Integrations list and in every Softr app.

    To rename, share, re-authenticate, or remove the connection, click the three dots next to it. Select **See active apps** to see which apps use it.
    <Frame caption="Click the three dots to rename, share, re-authenticate, or remove the connection">![Three dots menu of the ClickUp connection with the options See active apps, Share, Rename, Re-authenticate, and Remove](/data-sources/images/clickup/integrations-row-menu.png)</Frame>
  </Step>
  <Step title="Connect a block to your new ClickUp datasource">
    In any of your Softr apps, select a dynamic block, such as a List block. In the Source settings, select **ClickUp - [connection name]** as the **Account**.

    Then select the **Team**, the **Space**, and the **List** to show.

    <Tip>

    You can use any List from ClickUp, whether it is in a folder or not. Softr ignores the hierarchy in ClickUp and shows all Lists in a Space.
    </Tip>
    <Frame caption="Set the Account, Team, Space, and List in the Source settings of the block.">![Source settings of a List block with the ClickUp account, Team, Space, and List selected](/data-sources/images/clickup/block-source-settings.png)</Frame>

    Hover over a block to see which data sources it supports.
    <Frame caption="Hover over a block to see what data sources it supports.">![Block hover showing the data sources a block supports](/data-sources/images/clickup/block-supported-sources-hover.png)</Frame>
  </Step>
  <Step title="Map your ClickUp properties to the block elements">
    Click the block and select the **Content** tab. Map your ClickUp fields to the visual elements of the block.
    <Frame caption="Map the ClickUp fields to the block elements in the Content tab">![Content tab of a List block with the item fields name, status, and description mapped to the block elements](/data-sources/images/clickup/block-content-item-fields.png)</Frame>

    To map a field, click it and choose the field from ClickUp. For example, map an image element to the **Files** field.
    <Frame caption="Map an image element to a file field">![Image field settings with the Files field mapped to the cover media of the block](/data-sources/images/clickup/content-image-field.png)</Frame>

    You can add new fields, delete fields, duplicate fields, or change the styling of individual fields and elements. You can also change the field type if it does not match how you want it to display. Read more about mapping data [here](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/list-block/pQhPYuA28VXr5tLLFBcbCU#content).
  </Step>
  <Step title="Step 4 (optional): Create app users from ClickUp">
    You can sync a list of contacts or people in ClickUp so that they become Users of your Softr app. To learn more about users and how to sync them, check out [this article](/add-and-manage-users/pxnkp9H3qyEVMF6XUceqnj/syncing-users-with-a-data-source/hshRGygHr4T33EnaLntGf9).
  </Step>
</Steps>

## Softr Support for Tasks in Multiple Lists

ClickUp allows you to show tasks from one list inside other lists. Accessing these multiple lists is also possible in Softr, regardless of which list a task is housed in. For more information about these fields in ClickUp, see [this article](/add-and-manage-users/pxnkp9H3qyEVMF6XUceqnj/syncing-users-with-a-data-source/hshRGygHr4T33EnaLntGf9).

## ClickUp API Rate Limits

ClickUp has Rate limits based on the subscription plan on each Workspace level. This means that the rate at which you can read and interact with data from ClickUp will depend on your ClickUp plan. For API calls to ClickUp these are the current rate limits for ClickUp plans:

* Free Forever, Unlimited, and Business: 100 requests per minute per token.

* Business Plus: 1,000 requests per minute per token.

* Enterprise: 10,000 requests per minute per token.

## FAQ
   <AccordionGroup>
   <Accordion title="Can I use ClickUp data in Softr templates?">
Yes. Each Softr template comes with a sample Airtable base, so you can see how data is structured for the use case (e.g. client portal, inventory management). But you can use templates with another Softr-supported data source (like ClickUp), by connecting your own data. We recommend you follow the data structure in the sample base.
   </Accordion>
   <Accordion title="Can I pull in sub-tasks from ClickUp?">
Currently this is no supported, but we will be adding this soon! In the meantime, you can use our REST API datasource to pull in other resources from ClickUp like sub-tasks, built-in ClickUp comments, and more.
   </Accordion>
   <Accordion title="What is the heirarchy of supported ClickUp objects in Softr?">
Softr can connect one list to one block at a time. The list can be within a folder as well.
   </Accordion>

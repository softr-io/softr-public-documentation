# Workflows Integrations

Softr Workflows connect with third-party services so you can automate tasks across your stack. Add an integration as a trigger or as an action. In the **Select an action** window, the **Integrations** list shows every service. Use the search field to find one fast. Browse the integrations in the left menu to see what each one offers.

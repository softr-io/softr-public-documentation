<Steps>
  <Step>
    First, log in to your [Namecheap account dashboard](https://www.namecheap.com/myaccount/login/).

    <Frame>
      ![Notion image](/publishing/images/tutorial-how-to-set-up-a-custom-subdomain-for-namecheap/image1.png)
    </Frame>
  </Step>
  <Step>
    Next to the domain you want to point to Softr, click on **“Manage”**.

    <Frame>
      ![Notion image](/publishing/images/tutorial-how-to-set-up-a-custom-subdomain-for-namecheap/image2.png)
    </Frame>
  </Step>
  <Step>
    Click into the **“Advanced DNS”** tab. If you see **CNAME Record** and **URL Redirect Record** with parkingpage.namecheap like values please delete them.

    <Frame>
      ![Notion image](/publishing/images/tutorial-how-to-set-up-a-custom-subdomain-for-namecheap/image3.png)
    </Frame>

    If your screen doesn’t look like the image above, it’s most likely because you have your DNS pointed elsewhere. In other words, to create DNS records at Namecheap, you need to be using **“Namecheap BasicDNS”** which is included with every domain. You can check by going into the **“Domain”** tab.
  </Step>
  <Step>
    Click into the **“Advanced DNS”** tab and then click on “**Add New Record”.** If you see an A Record that already exists you will simply need to edit it (skip to the next step).

    <Frame>
      ![Notion image](/publishing/images/tutorial-how-to-set-up-a-custom-subdomain-for-namecheap/image4.png)
    </Frame>
  </Step>
  <Step>
    A subdomain needs a single **A record** — no CNAME. Set its **Host** to the subdomain label on its own, and its **Value** to the IP address Softr shows you under **Settings → Custom domain**.

    | Type | Host | Value |
    | --- | --- | --- |
    | A Record | the subdomain label only — `portal` for `portal.example.com` | the IP address Softr shows you |

    <Frame caption="Softr lists a single A record for a subdomain, and its Host is the subdomain label on its own.">
      ![Softr’s Custom domain panel for portal.example.net listing one A record whose host is portal and whose value is an IP address](/publishing/images/tutorial-how-to-set-up-a-custom-subdomain-for-namecheap/softr-subdomain-records.png)
    </Frame>

    Then create that same record in Namecheap:

    <Frame caption="The finished record in Namecheap’s Advanced DNS tab.">
      ![Namecheap’s Advanced DNS tab showing one A Record whose host is my and whose value is Softr’s IP address](/publishing/images/tutorial-how-to-set-up-a-custom-subdomain-for-namecheap/image5.png)
    </Frame>

    <Note>
      Unlike a root domain, a subdomain needs no CNAME record. If you have also followed the [top-level domain tutorial](/publishing/tutorial-how-to-set-up-a-custom-domain-for-namecheap), do not copy its `www` CNAME across.
    </Note>

    DNS changes can take a few hours to take effect.
  </Step>
</Steps>

**You are done!**

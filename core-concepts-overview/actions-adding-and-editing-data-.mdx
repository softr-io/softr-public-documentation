Actions make your app interactive. Users can do more than view data: they can create it, update it, and act on it. Softr has three types of actions:

* **Data actions:** Let users add, update, or delete records directly in the app.

* **Navigation actions:** Send users to another page, scroll to a section, or open an external link.

* **Advanced actions:** Run more complex operations, such as an API call that triggers an action in an external system (for example, Zapier or Make).

For actions that run in the background, with no user clicking a button, use [workflows](/workflows/workflows).

### **Data actions**

Data actions let users manage records directly in your app. You configure them on **dynamic blocks** such as [List](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/list-block/pQhPYuA28VXr5tLLFBcbCU), Grid, [Kanban](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/kanban/7y9bp8Z1ZkTZwpVRY8Ug1K), [Table](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/table-block-/j7rGwu7J7zuU69h3bZ7HFe), [Calendar](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/calendar/rdfXqxaPkTFioEbjBBAZai), [Inbox](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/layout-inbox/9cbSp8Mvwru9g6L6RM4uJ5), and [Item details](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/item-details-block-/4bE8XaFbJp45wkAwuWiz8f).

* [Add record](/actions/ntEfT9zSJk6aY54G6W5KGU/add-record/3LrUMpQY4BKfDDQj6eb8h8): Create a new record.

* [Edit record:](/actions/ntEfT9zSJk6aY54G6W5KGU/edit-record/irSJXPF1gCMXNmfsQFscvx) Change the details of one record.

* [One-click update](/actions/ntEfT9zSJk6aY54G6W5KGU/one-click-update/8BaX5i6KLZhZCrSZERGnej): Apply a predefined update to a record with one click.

* [Delete record:](/actions/ntEfT9zSJk6aY54G6W5KGU/delete-record/peV9LGdJbM9sKHKynqopkH) Delete a record.

**Example:** In a Sales CRM, users can edit client details and log activity with clients.

### **Navigation actions**

These actions send users to a page or an external destination. They work on both dynamic and static blocks.

* [Open page](/actions/ntEfT9zSJk6aY54G6W5KGU/item-on-click-actions/f1ns7phZfNNvgwXA6tTN3M): Go to another page in your app.

* [Open details page](/actions/ntEfT9zSJk6aY54G6W5KGU/item-on-click-actions/f1ns7phZfNNvgwXA6tTN3M): Open the details page of the selected record.

* [Open URL](/actions/ntEfT9zSJk6aY54G6W5KGU/item-on-click-actions/f1ns7phZfNNvgwXA6tTN3M): Send users to an external link.

* [Scroll to](/actions/ntEfT9zSJk6aY54G6W5KGU/item-on-click-actions/f1ns7phZfNNvgwXA6tTN3M): Scroll to a section of the page.

**Example:** In a Sales CRM app, clicking an account manager’s name in a list can **Open details page** to show their profile.

### **Advanced actions**

These actions cover more complex operations and custom integrations.

* **Block-specific actions:** Some blocks offer extra actions that fit their purpose. For example, the [Kanban](/building-blocks/vikC2AWEpQGkZd4jGyoVxo/kanban/7y9bp8Z1ZkTZwpVRY8Ug1K) block lets users drag cards between columns. See the documentation of each block for details.

* [Export](/actions/ntEfT9zSJk6aY54G6W5KGU/export/mnrvzncWeoSfwWJscZCAxC)**/**[Download](/actions/ntEfT9zSJk6aY54G6W5KGU/download-file/8Sr2y4CREVcW2GEEDYUhfJ): Export the visible records as PDF or CSV.

* [Call API](/actions/ntEfT9zSJk6aY54G6W5KGU/call-api/i9f1s3w9wib3oRmS4HZ7MX): Send a custom API call. *(Available for Professional, Business, and Enterprise plans)*

**Example:** In a real estate management app, a user clicks **Request an appointment**. The action triggers Zapier, which sends a Slack notification to the realtor.
